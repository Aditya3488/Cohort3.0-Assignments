Browser Rendering Pipeline

How your HTML & CSS become pixels on screen.

⟨/⟩ HTML Source
↓
🔍 Parsing

The HTML parser reads bytes and identifies meaningful units (tags, text, attributes).

↓
🔤 Tokenization

Raw characters are converted into typed tokens — StartTag, EndTag, Text, Comment, etc.

↓
🌳 DOM Tree

Tokens are assembled into a tree of Node objects that JavaScript can read and mutate.

+
↓
🖼 Render Tree

Only visible nodes are kept. Each node carries computed styles. This tree drives Layout & Paint.

↓
📐 Layout (Reflow)

Exact position and size of every box is calculated from the Render Tree.

↓
🎨 Paint & Composite

Pixels are drawn in layers, then composited into the final frame sent to the screen.

✦ CSS Source
↓
🔍 Parsing

CSS bytes are parsed into a rule list — selectors, declarations, at-rules.

↓
🎨 CSSOM Tree

Rules are organized into a style tree with specificity resolved and values inherited.

Attributes vs Properties

Type in the box below and watch the difference live.

getAttribute("value") initial
input.value (property) initial

Key insight: getAttribute("value") always returns the initial HTML attribute — it never changes unless you call setAttribute(). input.value is a live DOM property that reflects what the user typed. Attributes are in the HTML; properties are in the DOM object.
